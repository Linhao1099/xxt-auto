# 学习通全自动任务机 · xxt-auto

> 一个 **Tampermonkey 用户脚本**。进到一个章节，把这一页的**视频、长图、章节测验**全做完，再自动去**下一个有任务点的小节**。

## 为什么选它

同类工具不算少，但多数要你先付出一些成本才能跑起来：

| 方案 | 你要准备什么 |
| --- | --- |
| Python 脚本 | 装 Python、`pip install` 一堆依赖、改 config 文件、会跑命令行 |
| 服务端程序（Spring Boot / 云端刷课） | 装 JDK，配 MySQL、Redis，部署服务，还得长期维护一台机器 |
| 安卓 App | 装 APK、开无障碍权限、可能还要过应用商店的拦截 |
| **这个项目** | **装一个浏览器扩展 + 粘一段代码** |

没有 Python，没有 npm，没有数据库，没有服务器，不用注册任何账号。

浏览器装好 Tampermonkey 之后，**30 秒内**就能在学习通页面右上角看到工作面板，剩下的交给它。换台电脑要重装一次，但也就是重来一遍这 30 秒。

### 代价也说实话

它是**脚本**，所以受浏览器和页面结构限制：

- 学习通改版，脚本可能失灵，要跟着改
- **偶尔还是会漏一点** —— 某个视频没被认出来、某张长图没翻完、某道题没读到。这是这类工具的常态，没人能做到 100%
- 所以它带了一份「跳过账」（`xxt.skipped()`），把被迫跳过的小节记下来，你回头点一下手动补上就行

不承诺 100% 不漏。它追求的是：**安装成本低到可以随手试一下**，剩下那点小概率漏掉，你花两分钟手动补完。

## 它能干什么

一个章节页里可能同时挂着好几种任务点。脚本会逐个啃：

| 任务类型 | 它做什么 | 怎么判定做完了 |
| --- | --- | --- |
| **视频** | 自动起播、1.5x、静音、播完接下一个（同页多个视频连着放） | `ended` 或剩余不足 1.8 秒，且翻遍整页没有再冒出新视频 |
| **长图** | 从上往下一格一格滚到底，慢慢滚，不一下跳到底 | 所有能滚的容器都到底，再留 2 秒给平台记账 |
| **章节测验** | 还原加密题干 → 问 AI → 自动勾选项 / 填输入框 → 自动点「暂存」 | 保存完停 1.5 秒就走（找不到暂存按钮也走） |
| **文档 / PPT** | 自动往下推着翻 | 推不动了就算完 |

三类都清干净了，才按左侧目录跳到**下一个有任务点的小节**。目录里没标记的小节会越过，但最多连跳 2 个——标记系统延迟更新时，第三个不管有没有标记都进去看一眼。

> **脚本永远不点「提交 / 交卷」。** 按钮文字里只要带「提交」或「交卷」，一律不碰。提交那一步永远留给你。

## 安装

### 第 0 步：先搞明白你要装的是什么

Tampermonkey（中文一般叫「**油猴**」）是一个浏览器扩展。它的作用是：**允许你往任意网页里塞一段自己写的 JavaScript**。

这个项目就是那段 JavaScript —— 一个 `.user.js` 文件，170 KB 纯文本。装进 Tampermonkey 之后，每次打开学习通页面它就自动跑起来，在右上角画出一个面板。

所以要装的东西只有两样：**Tampermonkey 扩展** + **这一个脚本文件**。

> 不需要：Python、Node.js、命令行、数据库、服务器、注册账号、填个人信息。
> 只需要：一个能装扩展的浏览器（Firefox / Chrome / Edge 都行）。

---

### 第 1 步：装 Tampermonkey

#### Firefox（最简单）

1. 打开 <https://addons.mozilla.org/firefox/addon/tampermonkey/>
2. 点蓝色的「**添加到 Firefox**」，弹窗里再点「**添加**」
3. 浏览器右上角工具栏出现一个**黑色圆形小图标**（两个白点），就是装好了
   - 没看到图标的话，点工具栏最右边的「扩展」按钮（拼图形状），把 Tampermonkey 拖到工具栏上

#### Chrome / Edge

1. 打开扩展商店，搜 `Tampermonkey`
   - Chrome：<https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo>
   - Edge：<https://microsoftedge.microsoft.com/addons/detail/tampermonkey/iikmkjmpaadaobahmlepeloendndfphd>
2. 点「**添加到 Chrome**」/「**获取**」，确认「**添加扩展程序**」
3. ⚠️ **这一步千万别跳，不然装了也不工作**：
   - 点浏览器右上角的拼图图标（「扩展」）→ 找到 **Tampermonkey** → 点右边的「**⋮**」或「详情」
   - 在扩展详情页里找到「**允许用户脚本**」/ **Allow User Scripts**，把它**打开**
   - 如果页面上找不到这个开关，就把 `chrome://extensions` 页面右上角的「**开发者模式**」打开，开关才会出现
4. 回到工具栏，点拼图图标，把 Tampermonkey 的图钉点亮，让它常驻

> **判断有没有设对**：点一下 Tampermonkey 图标，正常情况下会弹出一个小菜单（已安装脚本列表）。如果点了毫无反应，或者提示"You need to enable user scripts"，就是第 3 步没做完。

> 国内 Chrome 扩展商店打不开的话：去 <https://www.tampermonkey.net/> 下载 `.crx` 文件，拖进 `chrome://extensions` 页面安装；或者干脆换 Edge，Edge 的扩展商店国内能直连。

---

### 第 2 步：装脚本

两种方式，随便选一种。**方式 A 失败就换方式 B**。

#### 方式 A：把文件拖进浏览器（最快）

1. 在本仓库里打开 [`dist/xxt-auto.user.js`](dist/xxt-auto.user.js)
2. 点页面右上角那个「**Download raw file**」按钮（一个向下的箭头图标）
   - ⚠️ **不要右键「链接另存为」**，那样存下来会变成 `xxt-auto.user.txt`，浏览器就不认了
3. 打开下载好的文件所在的文件夹
4. **按住这个文件，直接拖到浏览器窗口里松手**
5. Tampermonkey 会跳出一个安装页面，上面写着脚本名和「安装」按钮，点「**安装**」

> 拖拽没反应的话，说明文件后缀被改了。检查一下是不是 `.user.txt`，改成 `.user.js` 再拖。

#### 方式 B：复制粘贴（拖拽不管用时用这个）

1. 在本仓库里打开 [`dist/install.html`](dist/install.html)，点右上角「Download raw file」下载
2. **双击这个 html 文件**，用浏览器打开
3. 页面上点「**复制脚本全文**」按钮，按钮变绿就复制好了
4. 点浏览器右上角的 **Tampermonkey 图标** → 「**管理面板**」
5. 点左上角的「**+**」号（新建脚本）
6. 编辑器里会有一段默认模板代码，按 `Ctrl+A` 全选 → `Delete` 删干净
7. 按 `Ctrl+V` 粘贴
8. 按 `Ctrl+S` 保存
9. 关掉这个标签页

1. 打开学习通，随便进一门课，点进任意一个章节
2. 按 **F5 刷新一次**
3. 数到 3 秒左右，页面**右上角**会出现一个深色小面板，标题是 `学习通全自动 v3.3`

看到这个面板 = 装好了，可以开始用了。面板左上角有个绿点，表示正在运行。

### 装不上怎么办

<details>
<summary><b>右上角一直没有面板</b></summary>

按顺序排查：

1. **Tampermonkey 图标是灰的 / 带红色数字？** 说明扩展被禁用了，点图标 → 开启
2. **Chrome / Edge 用户**：回去检查 `chrome://extensions` 里的「开发者模式」是不是开着
3. **确认脚本在列表里**：点 Tampermonkey 图标 → 管理面板，应该有「学习通全自动（刷课 + 做题）」这一条，开关是**已启用**
4. **确认网址匹配**：脚本只在 `chaoxing.com` / `chaoxing.cn` / `edu.cn` 这三个域名下运行。如果你的学校用的是别的域名（比如某些自建平台），要自己往脚本头部加一行 `// @match *://*.你的域名/*`
5. **按 F12 打开控制台**，看 Console 标签里有没有 `[xxt]` 开头的日志。有日志说明脚本跑了但不显示面板；没有日志说明压根没加载
</details>

<details>
<summary><b>提示"无法安装此脚本" / 打开是乱码</b></summary>

浏览器把 `.user.js` 当成普通文本显示了。原因通常是：

- 文件后缀变成了 `.txt` → 改回 `.user.js`
- 用的是 Safari → Safari 不支持 Tampermonkey 的完整功能，换 Firefox 或 Chrome
- 用了某些下载工具，把文件内容损坏了 → 重新下载一次，或者改用方式 B
</details>

<details>
<summary><b>面板出来了，但什么都不做</b></summary>

先在控制台敲 `xxt.state()`，看它认为当前是什么状态：

- `section` 是空的 → 左侧章节目录没被识别，可能这页不是章节播放页
- `quizPhase: "none"` 但页面上明明有题 → 题目容器结构变了，提个 issue
- 一切正常但不动 → 敲 `xxt.tick()` 手动推一次，看有没有反应

</details>

脚本头部已经指向这个仓库：

// @downloadURL  https://raw.githubusercontent.com/Linhao1099/xxt-auto/main/dist/xxt-auto.user.js

想立刻检查一次：点 Tampermonkey 图标 → 「检查用户脚本更新」。

> **Fork 之后**要换成自己的地址，重新构建一次：
>
> ```bash
> XXT_REPO=你的用户名/xxt-auto npm run build
> ```

刷新页面后面板出现在右上角。

```
┌─ ● 学习通全自动 v3.3 ──────── [停止] [▸] [×]
│  章节：1.2 化学热力学
│  任务：视频 2/3 · 测验 12 题 · 已处理
├────────────────────────────────────
│  题目明文            ← 有测验时自动摊开
│  [1] 在一定温度下，发生变化的孤立体系…
│      A 不变
│      B 可能增大或减小
│  ...
│  答案：[D,B,A______] [填入] [问 AI] [暂存]
│  ☑自动问 AI ☑自动勾选 ☑自动暂存 ☑清完自动去下一节 ☐等交卷再走
│  答案已保存，准备去下一节
│  ▸ AI 设置
└────────────────────────────────────
```

### 五个开关

状态记在本机，下次打开还是你选的。

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| 自动问 AI | 开 | 读到题目就自己问一次，不用点按钮 |
| 自动勾选 | 开 | AI 出答案后自动点选项 / 填输入框 |
| 自动暂存 | 开 | 全部填好后自动点页面上的「暂存 / 保存」 |
| 清完自动去下一节 | 开 | 这页任务全清完就跳下一节 |
| 等交卷再走 | **关** | 关＝保存完就跳；开＝停在原地等你点提交 |

### 控制台命令

面板装不上的时候，这些都是趁手的排查工具：

| 命令 | 作用 |
| --- | --- |
| `xxt.stop()` / `xxt.start()` | 停止 / 继续 |
| `xxt.next()` | 手动跳下一个有任务点的小节 |
| `xxt.tasks()` | **这一页还剩什么**：每个视频播到哪、有没有记账、几个长图盒、几道题 |
| `xxt.skipped()` | **跳过账**：哪一节、什么时间、为什么跳过 |
| `xxt.state()` | 当前状态：确认阶段第几轮、测验到哪一步、错误信息 |
| `xxt.storage()` | 配置存在哪、会不会丢 |
| `xxt.cfg()` | 现在存着的 AI 配置 |
| `xxt.rate(2)` | 改倍速（1–4），会记住 |

## 配置 AI（可选）

不配也能用——题目照样还原成明文，你自己填答案就行。配了才能全自动答题。

展开面板底部的「AI 设置」：

| 字段 | 例子 |
| --- | --- |
| 接口地址 | `https://api.deepseek.com/chat/completions` |
| 密钥 | `sk-...` |
| 模型名 | `deepseek-chat` |

填完点「保存设置」，再点「测试连接」当场验一下，通了会显示 `✓ 通了（deepseek-chat）`。

任何 OpenAI 兼容的 `chat/completions` 接口都行（Kimi、通义、本地 ollama 都算）。

**配置存在油猴扩展自己的存储里**，不在页面里。所以换子域、关浏览器、关机重启都还在。

<details>
<summary>为什么不用 localStorage（旧版的坑）</summary>

旧版把配置写在网页的 `localStorage` 里，它有三个躲不开的毛病：

1. **按域名隔离**：`mooc1.chaoxing.com` 和 `mooc2-ans.chaoxing.com` 是两个不同的 origin，这边填的到那边读不到
2. **会被清**：Firefox 的隐私设置、清站点数据、网站自己发的 `Clear-Site-Data` 都能把它带走
3. **关机就没了**：浏览器清会话数据时它跟着走

现在用 `GM_setValue` / `GM_getValue`，同时往页面存储写一份兜底。旧版本残留在页面里的配置会在第一次运行时自动搬过去。
</details>

## 工作原理

### 1. 加密题干怎么还原

学习通给题目套了一个自定义字体：真字的**码位不变**，但字形被随机打乱。所以页面上看到的是「在一定嵣度嵦，发嵥嵢化的嵡嵧嵤系」——文字本身是错的。

但是：**每个字的轮廓形状是固定的，而形状到真字的对应关系是全局唯一且不变的**。

所以流程是：

```
页面里 <style id="cxSecretStyle"> 的 @font-face 带着 base64 TTF
        ↓ 解 base64
解析 TTF：head / maxp / loca / glyf / cmap 五张表
        ↓ cmap 给出「码位 → 字形编号」
逐个字形读轮廓点：每个点的 x、y、是否在曲线上
        ↓ 按顺序拼成字符串（无分隔符）
MD5 → 取前 10 位十六进制 → 查表得真字
```

`dist/font-table.txt` 就是这张表：**73975 个字符 = 6725 条记录**，每条 11 个字符（10 位 MD5 前缀 + 1 个真字）。

两份实现都在仓库里：

- 浏览器端：`src/xxt-all.js` 里的 `md5hex` / `Reader` / `parseCmap` / `hashGlyph`
- Node 端：`tools/ttf-decode.mjs`，导出了同一套函数，可以脱离浏览器单独跑

> 有意思的地方：这套算法的关键在于"原始数据的码位被随机洗牌"。所以**硬编码任何映射都无效**——每次刷新页面字体都会换一份码位，必须现场从 TTF 算。这也是为什么字形表存的是"形状指纹"而不是"码位"。

### 2. 三类任务并行泵

早期版本是串行的：

```
视频 → 长图 → 测验 → 翻屏确认 → 跳
```

每一环都靠"这一轮什么都没发生"往下走。结果：视频起不来 → 长图轮不到；长图没认出 → 测验轮不到；测验在等 AI → 视频轮不到。**任何一环误判，整页就被当成做完了**——漏任务基本都是这么来的。

现在每一轮都问一遍三类：

```js
function pumpAll() {
  var busy = false;
  var v = pickVideo();  if (v) { playVideo(v); busy = true; }   // 视频静音后台播
  if (scrollLong()) busy = true;                                // 长图慢慢翻
  if (quizTick() === 'busy') busy = true;                       // 测验推状态机
  return { busy };
}
```

谁有活谁干，全都不忙才进入确认阶段。

### 3. 怎么确认"这页真的做完了"

```
三类都停了
   ↓
往下推一屏（整页 + 每个 overflow 容器 + iframe 里的）
   ↓ 立刻重扫
   冒出东西？→ 回去干活
   ↓ 没冒出来
推够 12 轮，或者哪里都推不动了
   ↓
再确认一遍 → 才跳下一节
```

### 4. 为了少漏，做了这些

| 场景 | 这里的处理 |
| --- | --- |
| 同一段视频挂在两节 | 台账键 = `小节名@页面路径 \| 地址哈希#时长`，两节两条账 |
| 视频还没加载出来（`src` 为空） | 认不出就返回 `null`，**绝不拿去记账**，老老实实等它加载 |
| 长图懒加载（`naturalHeight` 是 0） | 四重判定：`naturalHeight` / `height` / `getBoundingClientRect().height` / 宽高比 ≥ 2.5 |
| 视频缩在内部滚动容器里 | `scrollEverything()` 找所有 `overflow-y: auto/scroll` 的容器，包括 iframe 里的 |
| 测验页 iframe 加载慢 | 基础耐心 20 秒，URL 含 `work/quiz/exam/homework/test` 直接翻倍到 40 秒 |
| 题卡上有"已作答"字样 | 交卷判定只认「已提交 / 已交卷 / 提交成功 / 本次成绩 / 总得分」这几个硬信号 |
| 不同章节的测验都从 `data="1"` 开始 | 题目指纹 = `小节名 \| 题数 \| 第一题 id`，换节必然重新解析 |
| 目录标记延迟更新 | 最多连跳 2 个没标记的小节，第三个必进 |
| 视频拉不起来 | 同一个视频试 40 次就放弃，并记进「跳过账」 |

### 5. 「不提交」是怎么保证的

```js
var NAMES  = ['暂存', '暂时保存', '保存答案', '保存草稿', '保存'];
var DANGER = /提交|交卷|交答案/;

// 按钮文字精确等于 NAMES 之一，且不含 DANGER，才算暂存按钮
```

另外几层：

- 暂存按钮优先在**最后一题往上三层**的范围内找，找不到才回退整个文档——不会点到笔记、讨论区的「保存」
- 查找时排除脚本自己的面板（面板里也有个「暂存」按钮）
- 点了暂存如果弹出确认框，弹窗文案含「提交 / 交卷」就立即停手，什么都不点
- 测试里专门有一条断言：整轮流程下来，页面上那个「提交」按钮的点击次数必须是 **0**

## 排查

**面板没出现** → 确认地址是 `chaoxing.com` / `chaoxing.cn` / `edu.cn`，然后刷新。

**题目还是乱码** → 面板里应该已经是正常字了。仍是乱码就把那段文字截图提 issue。

**一直卡在某一页** → 敲 `xxt.state()`，它会写卡在哪一步；敲 `xxt.tasks()` 看它眼里的任务清单。

**怀疑漏了** → 敲 `xxt.skipped()`，每个被迫跳过的小节都有记录，带时间和原因。点回目录手动补一下。

**题目读出来但没有答案**（没配 AI）→ 等 3 分钟会自己跳过，不会整晚卡着。

**配置老丢** → 敲 `xxt.storage()`，看 `hasGM` 是不是 `true`。如果是 `false`，说明油猴没给存储权限，去 Tampermonkey 设置里检查。

### 测试怎么跑的

`tests/all.mjs` 用 jsdom 造页面，把源码 `eval` 进去，然后断言行为。12 个场景：

| 场景 | 验证 |
| --- | --- |
| A 纯视频 | 起播、倍速、静音、播完切下一节 |
| B 纯测验 | 自动勾选 → 暂存 → 不等交卷就跳 |
| C 混排 | 视频先播完，再处理测验 |
| D 目录 | 越过没标记的小节 |
| E 只有提交按钮 | 存不上也先跳，提交点击 0 次 |
| F 等交卷再走 | 勾上后停在原地 |
| G 长图懒加载 | `naturalHeight` 为 0 也能认出并滚到底 |
| H 题目姗姗来迟 | 2.5 秒后才渲染的题，不许当空页面跳走 |
| I 「已作答」 | 不许误判成整卷已交 |
| J 两节同一视频 | 台账键必须带小节名 |
| K 配置持久化 | 旧数据迁移 + 「重启」后还在 |
| L 跨子域 | 在 mooc1 存的，mooc2-ans 也认 |

`tests/decode.mjs` 需要一份真实加密字体才能跑，没有就自动跳过（字形表已随仓库发布，日常不需要）。

## 已知限制

- **偶尔会漏**。脚本靠 DOM 特征去认任务点，页面结构或加载时序一变，就可能漏掉某个视频、某张长图、某道题。它带了「跳过账」（`xxt.skipped()`）把被迫跳过的小节记下来，你回头手动补一次就行——**别当成 100% 无人值守的解决方案**。
- **只在 Firefox 实测过**。代码没用什么 Firefox 独有的东西，Chrome / Edge 理论上一样，但没验证。
- **字形表覆盖 6725 个常用汉字**。生僻字解不出来会保留原样，不影响做题（题干里的生僻字很少）。
- **长图必须是真的能滚**。如果平台改成"播放动画"来记录阅读进度，这套逻辑就不适用了。
- **题目分页时不处理**。学习通有些作业分「单页 / 分页」两种展示，分页模式下脚本只处理当前页的题。
- **AI 答案的准确率取决于模型**。脚本只负责搬运，对不对得你自己判断——尤其是有填空、简答的卷子。
- **不点提交是硬编码的**。想全自动交卷的话这个项目帮不了你，也不打算做。
